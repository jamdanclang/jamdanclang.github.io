About the data

From public records to clear answers.

This project organizes official Nebraska Legislature records so they can be searched by legislative session.

How it works

1Collect

Download public records from the Nebraska Legislature.

→
2Prepare

Turn documents into searchable text and group them by session.

→
3Search

Send each question to the selected session notebooks.

→
4Answer

Return a concise response with links to supporting records.

The source records remain the authority. This tool helps people find and understand them; it does not provide legal advice.
